Privacy Policy

Last updated: August 18, 2026

Scope

ProAgentStore ("we", "our", "the platform") is a marketplace for server-powered AI agents. This policy covers the whole platform: the web console at proagentstore.online, the API, the MCP server, the @proagentstore/cli local runner, and the PAGS native app.

What we collect

  • Account identifiers from your GitHub or Google sign-in. We never receive or store a password.
  • Agent chat messages, responses, and the memory and knowledge you save to an agent.
  • Run records: instructions sent to an agent, tool calls and their results, terminal output, task and approval events, and how each run ended.
  • Repository metadata and, for agents you point at a repository, indexed file content.
  • Profile context and standing instructions you save for your agents.
  • Usage and cost records for the model calls your agents make.

Where it is stored

All account data is stored on Cloudflare — D1, R2, KV, Durable Objects and Vectorize. Each agent instance is an isolated Durable Object, and every request is scoped to the owning account.

Credentials and keys

API keys, site credentials and OAuth refresh tokens are envelope-encrypted before storage: an AES-256-GCM data key wrapped with AES-KW under a master key held as a Worker secret. Only your own model-provider key can be revealed back to your own browser, rate-limited. Gmail refresh tokens are never revealable. Encryption uses a service-held key, so this is not zero-knowledge: an operator with production access could decrypt stored credentials.

Your source code

Coding agents do not upload your repository. The coding CLI runs on your own machine and is reached over an outbound WebSocket that your machine initiates when you run pags up. Where you ask an agent to index a repository for search, the extracted text is stored in a vector store scoped to that instance and is deleted when you remove the repository.

Model providers

Agents run on a key you supply. Prompts and the context assembled for them are sent to the provider you chose — Anthropic, OpenAI, Google AI, OpenRouter, Groq, xAI, or Cloudflare Workers AI — under that provider's terms, using your key. We do not train models on your data.

Services you connect

Optional connectors reach a third party only after you authorize it and grant it to a specific agent: GitHub (a GitHub App, using per-installation tokens), Google Drive, Gmail (read-only), Zoho WorkDrive, and the Google Places API. Revoking a grant stops that access.

Tracking

No third-party advertising, no cross-app tracking, no third-party analytics.

Your responsibilities

Do not give an agent secrets, regulated data, or sensitive personal information unless you intend that agent and every tool you have granted it to process that data. An agent acts with the permissions of the credentials you give it.

Retention

Account data is retained to provide the service until you delete it. MCP audit events expire after 90 days. Deleting an instance deletes its messages, files, memory and indexed content. Deleting the native app removes local data from that device only.

Deleting your account

You can request permanent deletion at any time — see Delete Your Account & Data for what is deleted and what may be retained.

Open source

The platform is open source under the MIT licence at github.com/ProAgentStore/platform, so the behaviour described here can be verified in the source.
